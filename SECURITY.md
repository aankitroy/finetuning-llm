# Security policy

This project is a local learning tool. The progress dashboard binds to `127.0.0.1` only and never sends data anywhere.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately with GitHub's **"Report a vulnerability"** form under this repository's **Security** tab.

Include what you found, how to reproduce it, and which version or commit you tested. We aim to reply within a week.

## Supported versions

Only the latest commit on `main` is supported.
